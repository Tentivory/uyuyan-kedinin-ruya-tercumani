# Uyuyan Kedinin Rüya Tercümanı

> Resmî olmayan, fakat resmî duruşlu ulusal rüya tercüme protokolü.

Bu depo, uyuyan bir kedinin rüyasını **bilimsel ciddiyetle** Türkçeye çevirir.  
Kedi onay formunu imzalamaz. Onay formu zaten yalanmıştır.

## Neden var?

Çünkü asansörler terapi almıyor, çaydanlıklar fal bakmıyor, patatesler bu depoda yok.  
Geriye kedi kaldı. Kedi uyuyor. Biz tercüme ediyoruz. Medeniyet bu.

## Kurulum

```bash
python3 ruya_tercuman.py --kedi "Pamuk" --adet 5
```

Gizli protokol eki için (hiçbir şey değildir, merak etmeyin):

```bash
python3 ruya_tercuman.py --manifesto
```

## Bilimsel yöntem

1. Rastgele sahne seç.
2. Rastgele duygu ekle.
3. Rastgele sonuç yaz.
4. Bunu **protokol** diye sun.
5. Damgala.

Hata payı: yüzde yüz. Güvenilirlik: de damgalı.
